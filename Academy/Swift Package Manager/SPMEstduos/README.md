# 📦 SPMEstduos

App SwiftUI usado como **consumidor** do pacote local `UtilitiesKit` (pasta irmã), para praticar como adicionar e referenciar um Swift Package próprio dentro de um app via Swift Package Manager.

## 📂 Arquivos
| Arquivo | Descrição |
|---|---|
| `SPMEstduosApp.swift` | Ponto de entrada do app. |
| `ContentView.swift` | Tela inicial, ainda no template padrão do Xcode. |

O vínculo com o pacote `UtilitiesKit` está configurado como dependência local direto no `SPMEstduos.xcodeproj` (visível no `project.pbxproj`).
