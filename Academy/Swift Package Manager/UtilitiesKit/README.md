# 🔧 UtilitiesKit

Pacote Swift próprio (Swift Package Manager), criado para estudar como estruturar, versionar e consumir uma **biblioteca** local em outros projetos — usado pelo app `SPMEstduos` como dependência.

## 📂 Arquivos
| Arquivo | Descrição |
|---|---|
| `Package.swift` | Manifesto do pacote: define o produto `UtilitiesKit` como library e o target `UtilitiesKit`. |
| `Sources/UtilitiesKit/UtilitiesKit.swift` | Arquivo principal do módulo, ainda no template padrão gerado pelo SPM. |
| `HelloView.swift` | View SwiftUI de exemplo solta na raiz do pacote (fora de `Sources/`), com import do framework `Speech` — parece um rascunho de uma funcionalidade que ainda não foi movida para dentro do target. |
