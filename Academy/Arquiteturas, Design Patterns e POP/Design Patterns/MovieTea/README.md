# 🎬 MovieTea

Projeto UIKit criado para aplicar um design pattern em um app de catálogo de filmes. No estado atual do repositório o código-fonte (`AppDelegate`, `SceneDelegate`, `ViewController`) ainda é o template padrão gerado pelo Xcode, sem lógica de negócio ou pattern implementado — é um projeto em estágio inicial dentro dos estudos de Design Patterns.

## 📂 Arquivos
| Arquivo | Descrição |
|---|---|
| `ViewController.swift` | Controller inicial, ainda sem conteúdo além do `viewDidLoad()` padrão. |
| `AppDelegate.swift` / `SceneDelegate.swift` | Ciclo de vida padrão de um app UIKit. |
