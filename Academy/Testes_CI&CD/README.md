# iOS Testing Studies

Este repositório reúne dois projetos iOS de terceiros utilizados para fins de **estudo e prática de testes**. O código-fonte original não é de minha autoria — minha contribuição foi exclusivamente a execução e análise dos testes.

---

## 📁 Projeto 1 — ToDoMVC

| | |
|---|---|
| **Autor original** | Ryan Ashcraft |
| **Ano** | 2019 |
| **Copyright** | © 2019 Ryan Ashcraft. All rights reserved. |

### Sobre
Aplicação iOS no padrão **ToDoMVC** — uma implementação clássica de lista de tarefas usada como referência para comparar arquiteturas e frameworks.

### Minha contribuição
- Execução dos testes existentes no projeto
- Análise do comportamento da aplicação durante os testes
- Estudo da estrutura e padrões utilizados

### Como rodar os testes
```bash
# Abra o projeto no Xcode
open ToDoMVC.xcodeproj

# Execute os testes com o atalho
Cmd + U
```
