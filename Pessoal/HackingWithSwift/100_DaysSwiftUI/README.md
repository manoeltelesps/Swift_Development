# 💯 100 Days of SwiftUI

Exercícios feitos acompanhando o curso [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui), de Paul Hudson (Hacking with Swift). Cada dia é um playground independente, cobrindo os fundamentos da linguagem Swift antes de partir para SwiftUI propriamente dito.

## 📂 Conteúdo

| Playground | Tópicos |
|---|---|
| `Day2` – `Day4` | Variáveis, tipos básicos, operadores e os primeiros checkpoints do curso |
| `Day5` | Condicionais: `if`/`else`, `switch`, operador ternário |
| `Day6` | Loops: `while`, `continue`/`break` |
| `Day7` | Funções: escopo e retornos |
| `Day8` | Tratamento de erros e checkpoint |
| `Day9` | Closures, incluindo ordenação customizada com `sorted(by:)` |
| `Day10` | Propriedades e métodos, property observers, inicializadores |
| `Day11` | Métodos e propriedades estáticas |
| `Day12` | Classes: herança, cópia por referência, `deinit` |
| `Day13` | Protocolos e extensions |
| `Day14` | Optionals e `guard let` |
